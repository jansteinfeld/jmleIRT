# Log-likelihood for jmleIRT objects

Computes the joint log-likelihood of the Rasch model at the JMLE
estimates.

## Usage

``` r
# S3 method for class 'jmleIRT'
logLik(object, ...)
```

## Arguments

- object:

  An object of class `"jmleIRT"`.

- ...:

  Currently unused.

## Value

An object of class `"logLik"`.
